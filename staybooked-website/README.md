# Stay Booked Marketing | Website

staybookedmarketing.com. Vite + React + TypeScript, deployed on **Vercel** from `main` of github.com/jjordanvvo/staybookedmarketing (every push to `main` goes live).

## Commands

```
npm install
npm run dev        # local dev server
npm run build      # typecheck + build + prerender SEO pages and sitemap
npx tsx scripts/build-answers.ts   # regenerate public/answers/*.html + llms.txt
```

## Where things live

| What | Where |
|------|-------|
| Homepage sections | `src/components/sections/` (order in `src/pages/Home.tsx`) |
| Industries / niche pages | `src/lib/niches.ts` |
| Founders | `src/lib/founders.ts` |
| FAQ | `src/lib/faqs.ts` |
| Booking link (every Book a Call button) | `src/lib/booking.ts` |
| Calculator lead relay | `src/lib/leads.ts` |
| Growth Calculator (standalone page) | `public/growth-calculator/index.html` |
| AI-search answer pages | generated by `scripts/build-answers.ts` into `public/answers/` |
| Styles | `src/index.css` |

## Environment (Vercel)

- `VITE_META_PIXEL_ID`: Meta Pixel (also in `.env.production`)
- `VITE_CHAT_WIDGET_ID`: GoHighLevel chat widget (also in `.env.production`)
- `VITE_GA4_ID`: Google Analytics 4 (optional)
- `VITE_BOOKING_EMBED_URL`: calendar embed for `/book` (optional; without it `/book` shows a button to the Google Calendar link)

## Copy rules

No em dashes in site copy, nothing AI-sounding. Keep "We don't chase leads. We book them." and "Founded by Stanford graduates".
